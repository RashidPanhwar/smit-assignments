# SMIT HTML Assignments

This repo contains HTML assignments completed as part of the SMIT (Saylani Mass IT Training) web development program. Each assignment focuses on a core HTML concept, progressively building toward a multi-page website.

---

## Assignments

### Assignment 01 — School Formal Letter
A styled formal letter written in HTML, demonstrating document structure, typography, and basic CSS for a print-style layout.  
🔗 [Preview](https://rashidpanhwar.github.io/smit-assignments/assignment_01/school_formal_letter.html)

---

### Assignment 02 — Nested Lists
Practice with ordered and unordered HTML lists, including nested structures using real-world course catalog examples.  
🔗 [Preview](https://rashidpanhwar.github.io/smit-assignments/assignment_02/assignment_2_lists.html)

---

### Assignment 03 — E-Learning Website
A multi-page website (Home, About, Courses, Contact) built with semantic HTML and CSS, simulating a real e-learning platform.  
🔗 [Preview](https://rashidpanhwar.github.io/smit-assignments/assignment_03_elearning_website/index.html)
